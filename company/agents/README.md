# 에이전트 역할 골격
이 디렉터리는 역할과 인수인계 규약이다. 상시 실행되거나 자동 게시하는 에이전트가 설치된 상태는 아니다.

| 역할 | 입력 | 산출물 | 완료 기준 |
|---|---|---|---|
| Research | 사용자 지정 주제, 공개 자료 | 출처·확인일이 있는 콘텐츠 제안 | 사실/추정 분리 |
| Content | 승인된 주제, JSON 구조 | 질문·선택지·결과 JSON | 모든 결과 도달 가능, 중복·비하 없음 |
| Builder | 콘텐츠와 기능 요청 | 변경 코드 및 PR 초안 | 정적 제약 준수 |
| QA | 변경 내용 | 테스트 결과·화면 검토 | 링크 호환·공유·모바일 확인 |
| Publisher | 통과한 변경 | Pages 배포 상태와 URL | 실제 공개 URL에서 확인 |

기본 순서: 제안 → 콘텐츠 작성 → 구현 → QA → main 반영 → GitHub Actions 배포.
권한은 저장소 작업에 필요한 최소 범위로 제한하고 토큰은 파일에 넣지 않는다.
SNS 계정 연결·자동 홍보·유료 모델 실행은 별도 승인과 구성이 필요하다.
