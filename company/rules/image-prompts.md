# 캐릭터 이미지 프롬프트 기준

사용 도구: OpenAI 내장 이미지 생성기.

최종 공통 프롬프트는 “한국 인디 잡지와 리소그래프 포스터 같은 사람이 직접 편집한 평면 캐릭터 시트, 굵고 약간 떨리는 검은 윤곽, 종이 질감과 하프톤, 제한된 검정·코발트·토마토·애시드 라임·웜화이트 팔레트, 셀마다 한 캐릭터 전신, 배경은 단순한 기하 도형”이다. 이미지에는 글자·로고·워터마크·가짜 문자를 넣지 않는다. 광택 3D, 매끈한 벡터 스티커, 네온 글로우, 영화 조명, 과한 디테일, 생성형 이미지 특유의 장식과 손 오류를 피한다.

- `group-types.png`: 점화형, 추진형, 공감형, 큐레이션형, 관찰형, 탐험형을 왼쪽 위부터 3×2 순서로 배치.
- `extra-types.png`: 중재형, 기록형, 감각형, 창작형을 왼쪽 위부터 2×2 순서로 배치.
- `manual-types.png`: 고요형, 연결형, 탐험형, 완료형을 위에서 아래 2×2 순서로 배치.
- `manual-more-types.png`: 자연형과 놀이형을 2×1로 배치. 빛 번짐 없이 평면 잉크와 종이 질감만 사용.
- `fantasy-types.png`: 전사, 나이트, 힐러/수도사, 검사, 마법사, 궁수, 로그, 바드, 연금술사, 소환사, 가디언, 드래곤라이더를 4×3 순서로 배치. 무기는 단순하고 비폭력적인 소품으로 표현.
- `og-base.png`: 오른쪽에 여러 테스트 캐릭터가 모인 편집 포스터 장면, 왼쪽 절반은 정확한 한글 타이포그래피를 나중에 합성할 수 있게 비움.

한글 제목과 브랜드 문구는 이미지 생성 단계에서 만들지 않고 `scripts/create-og.ps1` 또는 Canvas로 합성한다.
