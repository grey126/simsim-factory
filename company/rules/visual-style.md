# 심심공장 이미지 제작 기준

## 목표
사람이 주제를 정하고 직접 편집한 독립 잡지나 소규모 브랜드의 결과물처럼 보이게 한다. 생성형 이미지 특유의 과장된 완벽함보다 구체적인 소재, 담백한 빛, 편집 의도가 드러나는 구성을 우선한다.

## 기본 선택 순서
1. CSS와 실제 글꼴로 만든 타이포그래피
2. 라이선스를 확인한 실제 사진
3. 종이, 잉크, 스캔, 콜라주처럼 물성이 느껴지는 창작 이미지
4. 생성 이미지가 꼭 필요한 경우에도 한 장면과 한 소재에 집중한 단순한 구성

## 피해야 할 표현
- 광택이 강한 3D 아이콘과 풍선 같은 캐릭터
- 보라·파랑 네온 그라데이션과 과한 림라이트
- 피부와 사물이 지나치게 매끈한 광고 사진
- 화면을 채우기 위한 무관한 소품과 입자
- 중앙에 모든 것을 완벽하게 맞춘 대칭 구도
- 읽을 수 없는 글자와 로고를 이미지 안에 생성하는 방식
- 손가락, 치아, 귀, 안경, 그림자, 반사, 반복 패턴이 어긋난 결과

## 검수 질문
- 이 이미지가 어떤 실제 촬영 방식이나 인쇄 방식으로 만들어졌는지 설명할 수 있는가?
- 이미지의 초점이 한 문장으로 명확한가?
- 장식 하나하나에 이유가 있는가?
- 한글과 숫자가 정확한가?
- 확대했을 때 형태, 원근, 광원, 재질이 자연스러운가?
- 흔한 AI 이미지 갤러리에 그대로 섞일 법한 인상은 없는가?

하나라도 만족하지 못하면 수정하거나 사용하지 않는다.
