# MVP 검증 기록

검증일: 2026-09-22 (Asia/Seoul)

- Node test: 9/9 통과. UTF-8/이모지 링크 왕복, 잘못된 payload 거부, 점수, HTML 이스케이프, 결과별 도달성, 결정적 채점, 외부 의존성 부재.
- 로컬 브라우저: 단톡방 12문항 전체, 인생 사용설명서 8문항 전체, 친구 퀴즈 생성→초대→8문항→100점 결과 확인.
- 실제 Pages: 홈 및 JSON 로딩, 인생 사용설명서 8문항 완료, 결과 링크 복사 성공 안내, Canvas 결과 카드 표시.
- 실제 Pages: 잘못된 초대 링크 오류 안내, 이전 질문으로 돌아갈 때 선택 답변 유지.
- 390px 모바일과 데스크톱 화면을 시각 확인. 모바일 가로 넘침 없음. 좁은 카드 장식 글자 크기 보정.

- 브라우저 오류 로그 없음.
