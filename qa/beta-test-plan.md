# 오루완 실제 사용자 테스트

## 대상과 방식

- 휴대폰 사용자 5명: 직장인 3명, 학생·프리랜서 2명 권장
- 테스트 링크: https://grey126.github.io/simsim-factory/
- 진행 시간: 1명당 8~10분
- 진행자는 화면을 대신 누르거나 기능을 설명하지 않고 관찰만 한다.

## 참가자에게 줄 과제

1. 첫 화면에서 가장 끌리는 테스트를 골라 결과까지 진행한다.
2. 결과가 자신과 얼마나 비슷한지 1~5점으로 말한다.
3. 결과 이미지를 저장하거나 휴대폰 공유 메뉴를 연다.
4. 판타지 직업 테스트를 찾아 결과까지 진행한다.
5. 친구 퀴즈를 만들고 링크를 복사한다.

## 관찰할 항목

- 첫 테스트를 고르기까지 10초 이상 걸리는가
- 질문 또는 선택지를 다시 읽는가
- 결과 키워드와 캐릭터를 바로 이해하는가
- 저장·공유 버튼을 한 번에 찾는가
- 화면이 잘리거나 가로로 밀리는가
- 막힌 지점, 웃은 지점, 공유하고 싶다고 말한 지점을 그대로 기록한다

## 통과 기준

- 5명 중 4명 이상이 도움 없이 첫 결과까지 완료
- 중간 이탈 없이 테스트 1개를 2분 안에 완료
- 5명 중 4명 이상이 결과 유형을 자신의 말로 설명
- 5명 중 4명 이상이 저장 또는 공유 기능을 발견
- 치명적인 잘림·빈 이미지·진행 불가 0건
