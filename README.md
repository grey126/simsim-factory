# 오루완 (OLTD)

**오늘도 루팡 완료.** 서버·DB·로그인 없이 가볍게 즐기는 무료 캐릭터 테스트 사이트입니다.

- 공개 사이트: https://grey126.github.io/simsim-factory/
- 친구 퀴즈: 8개 취향 선택 → URL fragment 초대 링크 → 친구의 정답률 확인
- 단톡방 캐릭터: 12문항 → 점화형·중재형·기록형 등 8개 결과
- 내 인생 사용설명서: 8문항 → 고요형·감각형·놀이형 등 8개 결과
- 판타지 직업: 9문항 → 전사·힐러·마법사·드래곤라이더 등 12개 결과
- 결과 이미지: 브라우저 Canvas로 1080 × 1920 PNG 생성
- 공유: Web Share 지원 시 기기 공유 메뉴, 미지원 시 링크 복사 또는 이미지 다운로드

## 개발과 배포

Node 20 이상. 외부 패키지 설치는 없습니다.

```sh
npm test
npm run build
npm start
```

미리 보기: http://127.0.0.1:4173/simsim-factory/
`npm start`는 개발 확인용 정적 파일 서버이며 실제 서비스에는 서버 프로그램이 없습니다.

GitHub Pages의 Source는 GitHub Actions입니다. `main`에 push하면 콘텐츠 검사와 빌드 후 `dist`만 배포하며, PR은 검증만 실행합니다. 외부 유료 서비스나 API 키를 사용하지 않습니다.

## 구조

- `index.html`, `assets/`: 공통 페이지·편집 디자인·캐릭터·SNS 미리 보기
- `js/app.js`: 화면과 URL fragment 라우팅
- `js/core.js`: 정답 처리, 점수, 입력 검증
- `js/share.js`: 캐릭터 결과 이미지 생성·저장·공유
- `content/*.json`: 질문·간결한 선택지·8~12개 결과 유형
- `scripts/build.mjs`: 공개 파일만 `dist`에 복사
- `scripts/create-og.ps1`: 공통 SNS 미리 보기 이미지 재생성
- `qa/`: 자동 검사와 실제 사용자 테스트 안내
- `company/`: 브랜드·콘텐츠·이미지 원칙과 에이전트 역할

새 콘텐츠는 JSON과 화면 엔진을 분리해 관리합니다. 종류를 추가할 때는 `app.js`의 로딩 목록·홈 카드·허용 경로에도 등록해야 합니다.

## 공유와 개인정보

친구 퀴즈의 별명과 정답은 링크의 `#` 뒤에 포함됩니다. 일반 HTTP 요청에는 fragment가 전송되지 않지만 암호화는 아닙니다. 링크를 가진 사람은 답변을 디코딩할 수 있으므로 민감한 정보를 넣지 않도록 안내합니다.

답변·진행 상태·참여자 순위는 저장하지 않습니다. 친구 점수는 만든 사람에게 자동 전송되지 않으며 점수 이미지를 수동 공유합니다. 분석·광고·추적 스크립트도 없습니다.

SNS 봇은 `#` 뒤를 읽지 않으므로 모든 링크는 공통 오루완 미리 보기를 사용합니다. 개인별 동적 OG 이미지와 자동 SNS 게시 기능은 없습니다.

## 콘텐츠 유지보수

질문은 가볍고 선택지는 한눈에 고르게 씁니다. 분류형 테스트는 8~16개 유형과 명확한 키워드·캐릭터를 제공합니다. 동점이면 JSON 결과 배열에서 앞선 유형을 사용하며 과학적 타당성을 주장하지 않습니다.

공유된 친구 링크 호환을 위해 v1 질문과 선택지 순서는 변경하지 않습니다. 필요하면 v2 데이터를 별도로 만들고 기존 디코더를 유지합니다.

GitHub Pages의 사업·상업적 이용에는 제한이 있습니다. 이 MVP는 광고와 결제 없는 무료 놀이입니다. 광고 수익화 전 [공식 정책](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)을 다시 검토합니다.
